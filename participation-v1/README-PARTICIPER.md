# TRIADE — le pack pour évaluer ou contribuer (v1.0.0, 24 novembre 2026)

Ce pack rassemble en un seul endroit tout ce qu'il faut pour **juger** le protocole
TRIADE et pour **y ajouter sa pierre**, sans rien reconstituer.

## Ce qu'il contient

| Élément | Fichier | À quoi il sert |
|---|---|---|
| Le complet | `kits/TRIADE_complet_v0.25.0.zip` | sources des cinq pièces, ateliers, plans gelés, scripts, instructions exécutées, journal des décisions |
| La présentation | `kits/TRIADE_presentation_v0.25.0.zip` | les cinq pièces régénérées (manuscrit v0.25.0, spécification v0.15.10, Livre v1.9, preuves, présentation) |
| Le kit développeur | `kits/TRIADE_kit_developpement_v1.2.0.zip` | la méthode pas à pas : cérémonies, gabarits, GUI, politique de sécurité, liste blanche du prescriptif |
| Le pack d'entraînement | `kits/TRIADE_train_v1.0.0.zip` | recettes SFT/DPO/RLVR, 48 paires de préférence, carte du corpus v2.1 |

## Par où commencer

1. **Évaluer** : `EVALUATION.md` — six commandes, chacune avec son résultat attendu.
2. **Contribuer** : `CONTRIBUTING.md` — le plan gelé avant la donnée, l'append-only, la
   liste blanche du prescriptif, les refus nommés.
3. **Citer** : `INDEX-DOI.md` — les identifiants de chaque œuvre (protocole, corpus,
   entraînement, kit).

## Ce que ce pack n'est pas

Ce n'est pas une distribution du code machine : les artefacts scellés vivent dans le
complet et sur Zenodo, jamais dans un binaire exécutable non vérifié. Il ne contient
aucun secret, aucune clé, aucune donnée personnelle. La licence du projet est BSL 1.1
(voir le complet) ; le corpus est en CC-BY-4.0.
