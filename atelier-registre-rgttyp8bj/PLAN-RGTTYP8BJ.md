## 1. LA RÈGLE (gelée)

Le manuscrit académique (TRIADE_manuscrit, l'anglais) est révisé AU
REGISTRE NEUTRE SCIENTIFIQUE :
 — le lexique RITUALISTE ET PROMOTIONNEL remplacé : « le geste du
   maître » (the master's gesture) → la décision/le geste opératoire
   DU DÉVELOPPEUR, nommé sobrement (« the developer's explicit
   decision/command ») ; « la vague N » (the wave N) → le lot
   d'instructions / la campagne d'instructions N (« instruction batch
   N », la série) ; « l'objectif TENU » (the objective held/TENU) →
   « the criterion was met » (le critère satisfait) ; « X× de marge »
   (margin) → l'écart mesuré rapporté en rapport de coûts (« a factor
   of X below the reference ») ; les MAJUSCULES DE VICTOIRE (HELD,
   TENU, VERT en capitales d'emphase) → la casse normale ;
 — CHAQUE TERME MAISON défini UNE SEULE FOIS (à sa première
   occurrence) puis employé SOBREMENT (la notation, la carte, le
   coffre, le scellé, le témoin, la cristallisation, l'oracle, le
   terrain — les définitions une fois, l'usage ensuite en casse
   normale) ;
 — LA TRANSPARENCE INTACTE : les falsifications, les retraits, les
   échecs, les gaps demeurent rapportés AU MÊME NIVEAU DE DÉTAIL (la
   révision du registre NE RETIRE AUCUNE pièce de transparence) ;
 — AUCUNE VALEUR NUMÉRIQUE MODIFIÉE ; AUCUNE revendication renforcée
   au-delà de ce que les pièces supportent (la révision de registre
   N'AJOUTE AUCUN claim) ;
 — LES PIÈCES OPÉRATOIRES FRANÇAISES (le Livre du Coffre, la
   spécification) GARDENT LEUR STYLE (aucune modification de registre
   hors le manuscrit académique) ;
 — les citations VERBATIM des pièces (les consoles, les refus nommés,
   les empreintes) demeurent OCTET-POUR-OCTET (le verbatim des pièces
   d'origine n'est pas du lexique révisable).
