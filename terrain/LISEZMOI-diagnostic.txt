================================================================================

superviseur-terrain3.exe est le BON (md5 40b2f350ad8556d028d431174d429189,

mes validateurs précédents (qui avaient béni terrain.2 à tort) :
  - en-têtes PE : toutes les règles du chargeur Windows sont vertes
    (SizeOfHeaders 0x400 correct, 6 sections saines, point d'entrée

  - les 42 entrées d'importation correspondent EXACTEMENT aux fonctions

VÉRIFICATIONS MANUELLES — 30 SECONDES, AVANT MÊME LE KIT :
  1. Après un double-clic « silencieux » : le fichier superviseur-
     terrain3.exe EXISTE-T-IL TOUJOURS dans le dossier ? S'il a
     DISPARU, c'est la preuve immédiate de la quarantaine.
  2. Sécurité Windows -> Protection contre les virus et menaces ->
     Historique de protection : cherchez une entrée récente mentionnant
     superviseur-terrain3.exe.

LE KIT — 3 ÉTAPES :
  1. Téléchargez DIAGNOSTIC-SUPERVISEUR.cmd (dossier test ou racine du
     Drive) et posez-le dans le MÊME dossier que superviseur-terrain3.exe.
  2. Double-cliquez-le. Si Windows affiche l'écran bleu SmartScreen
     (« Windows a protégé votre PC ») : « Informations complémentaires »
     puis « Exécuter quand même » — c'est un simple script de lecture,
     il n'installe rien.
  3. Une fenêtre console noire défile (environ 10 à 30 secondes) ; le
     script relance UNE FOIS superviseur-terrain3.exe sous surveillance
     — si la fenêtre TRIADE apparaît enfin, fermez-la pour laisser le
     script terminer. À la fin, le fichier rapport-diagnostic.txt est
     posé à côté : DÉPOSEZ-LE dans le dossier « test » du Drive.

CE QUE CONTIENDRA LE RAPPORT (tout est automatique) :
  [0] version de Windows          [4] état de Defender
  [1] présence du fichier         [5] les 8 dernières menaces détectées
  [2] md5 du fichier              [6] les crashs applicatifs récents
  [3] marque du téléchargement    [7] code de sortie du lancement surveillé
      (SmartScreen)                   + le fichier a-t-il survécu
  [8] contenu final du dossier

SI L'ANTIVIRUS EST CONFIRMÉ : l'exclusion de dossier (Sécurité Windows
-> Protection contre les virus et menaces -> Gérer les paramètres ->
Exclusions -> Ajouter un dossier -> votre dossier de test) débloque le
run immédiatement — la procédure détaillée est dans LISEZMOI-superviseur.
Le rapport me dira laquelle des deux routes prendre.
