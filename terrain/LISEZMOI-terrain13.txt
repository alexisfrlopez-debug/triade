LA NOUVELLE, EN PREMIER
-----------------------
Vous écrivez : « journaux envoyés, mais je n'ai pas le json google dans le
dossier ». Il y a DEUX explications, et les deux sont de notre côté.

1) LE JSON NE POUVAIT PAS EXISTER — NOS EXCUSES.
   La commande curl embarquée dans le superviseur portait l'option « --fail ».
   Cette option fait précisément ceci : quand le serveur Google répond par
   une erreur, curl s'arrête SANS ÉCRIRE LA RÉPONSE. Le fichier
   terrain_jeton.json n'était donc jamais créé — nous vous avons demandé une
   pièce que notre binaire ne pouvait pas produire. C'est corrigé dans ce
   terrain.13 : l'option est retirée des deux requêtes Google. Maintenant,
   si Google répond — même par un refus — le fichier existera, avec le
   message d'erreur exact dedans (jeton expiré, horloge, identifiants…).
   Il ne contient AUCUN secret.

2) VOTRE RUN DE 22:32 A TOURNÉ SUR L'ANCIEN SUPERVISEUR (TERRAIN.11).
   Son journal commence par « S00 superviseur terrain 0.5.0-terrain11 » et
   l'empreinte de la démo (S04C cf72462d…) est celle de l'ancienne démo de
   diagnostic — pas celle de la démo finale (73c064fb…) embarquée dans
   terrain.12. Le terrain.12 n'a jamais tourné : deux fichiers presque
   identiques côte à côte, la confusion est humaine. Le protocole ci-dessous
   commence donc par un NETTOYAGE qui rend la confusion impossible.

Au passage, bonne nouvelle dans ce run : le test T2 est resté VERT pour la
3e fois d'affilée. La stabilité se confirme.

SI LE JSON N'APPARAÎT TOUJOURS PAS
----------------------------------
Alors curl n'atteint même pas Google (problème réseau). Dans ce cas :
   1. Ouvrez le dossier du superviseur dans l'Explorateur ;
   2. Cliquez dans la BARRE D'ADRESSE, tapez « cmd », Entrée — une fenêtre
      noire s'ouvre directement dans le bon dossier ;
   3. Collez cette ligne puis Entrée :
      curl.exe -v --max-time 30 -o terrain_jeton_reseau.txt --data @terrain_req.txt https://oauth2.googleapis.com/token
   4. Envoyez une capture d'écran de la fenêtre (elle montre les étapes
      réseau, sans aucun secret) et déposez terrain_jeton_reseau.txt
      s'il apparaît.
