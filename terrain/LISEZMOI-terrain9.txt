POURQUOI TOUT S'EST FERMÉ TOUT SEUL : C'EST L'ANTIVIRUS
--------------------------------------------------------
L'enquête (menée octet par octet sur les journaux et le binaire) a
éliminé toutes les causes internes : chaque appel effectué par le
superviseur à cet instant précis avait DÉJÀ fonctionné une minute plus
tôt dans le même run, et une fermeture manuelle n'aurait pas pu couper
le journal à cet endroit-là. Reste un seul coupable, et il est externe :
WINDOWS DEFENDER. Les faits qui l'accusent :
  - votre antivirus a déjà signalé proxy.exe une fois ce jour-là
    (12:55, détection enregistrée) ;
  - la surveillance « comportementale » est active sur votre machine ;
  - la fermeture simultanée de TOUTES les fenêtres d'un coup est la
    signature d'un antivirus qui tue une famille de processus — pas
    d'un plantage (un plantage laisse un message d'erreur et ne ferme
    pas les voisins) ;
  - c'est arrivé DEUX FOIS exactement au même point : l'instant où le
    trafic réseau externe commence à passer par le proxy.

POURQUOI IL FAIT ÇA : nos exécutables sont du code machine écrit à la
main, sans signature numérique. Pour l'antivirus, « un programme qui
dépose d'autres programmes, les lance, et relaie du trafic réseau »
ressemble à un cheval de Troie — c'est un FAUX POSITIF : ces binaires
sont les nôtres, vérifiés octet par octet, ils ne contiennent que notre
propre code. Il faut simplement dire à Defender de les laisser
tranquilles. C'EST LA SEULE CHOSE QUI CHANGE DANS CETTE ITÉRATION.

AVANT LE RUN : L'EXCLUSION (5 MINUTES, UNE SEULE FOIS)
------------------------------------------------------
1. Créez un dossier dédié, par exemple  C:\TRIADE
   (Explorateur → Ce PC → Disque local (C:) → clic droit → Nouveau →
   Dossier → nommez-le TRIADE).
2. Téléchargez superviseur-terrain9.exe depuis ce dossier test et
   PLACEZ-LE DANS C:\TRIADE — pas dans Téléchargements (Defender
   surveille davantage les fichiers téléchargés).
3. Ouvrez « Sécurité Windows » (touche Windows, tapez « Sécurité
   Windows », Entrée).
4. Cliquez « Protection contre les virus et menaces » → « Gérer les
   paramètres » (sous Paramètres de protection contre les virus et
   menaces) → descendez jusqu'à « Exclusions » → « Ajouter ou
   supprimer des exclusions ».
5. « Ajouter une exclusion » → « Dossier » → choisissez C:\TRIADE →
   validez. Si Windows demande une autorisation administrateur :
   Oui. Le dossier doit apparaître dans la liste des exclusions.
