# PLAN GELÉ — VPCR7MH3T (la vague 15)
> L'atelier eval : livrer l'eval mécanique re-jouable sur tout modèle à toute
> version de kit, sans dorées publiées — la ladder anti-récitation et l'anti-gaming.
> Gelé AVANT toute mesure ; le plan pré-enregistré (empreinte gelée AVANT).

## Le mandat
(1) **LES JUGES EN HARNAÏS RUNNABLE** : round-trip keystone==capstone==keystone,
juge d'expansion, oracle différentiel, batterie de mutation, certificats z3 ;
les 18 tâches held-out SANS notation dorée (validateurs seulement).
(2) **LA CAPABILITY LADDER** : rung 0 récitation 128 constantes (attendu échec),
rung 1 dérivation depuis définitions (zéro divergence), rung 2 localiser (4
refus fail-closed), rung 3 éditer, rung 4 ajouter, rung 5 boucle complète,
rung 6 terrain (geste développeur, non contaminable) — chaque rung NOMME la
frontière du modèle, jamais une moyenne trompeuse.
(3) **LE GÉNÉRATEUR PROCÉDURAL de tâches d'eval** (contrats neufs depuis la
grammaire, blocs neufs depuis le générateur) pour régénérer le held-out à chaque
version — l'eval RÉSISTE à la contamination ; les contrôles de falsification
(une notation mutée DOIT être refusée, une tentative de jouer le juge DOIT être
attrapée) ; LA MATRICE de compatibilité checkpoint↔kit↔juges fail-closed.

## Les gestes
1. Le plan gelé ; le harnais (les juges runnable, les 18 tâches sans dorées).
2. La ladder 0–6 (les rungs 0–5 automatisés, le rung 6 au geste nommé).
3. Le générateur procédural (grammaire + générateur de blocs, graines consignées).
4. Les contrôles de falsification + la matrice de compatibilité.
5. Le plan gelé d'empreinte AVANT toute mesure.

## La vérification après modifications
Juges intacts (mutant attrapé au premier vecteur, gle 87 → −6) ; intégrité
held-out (aucune dorée ne fuite, canari vérifié) ; sonde de contamination
re-jouée ; graines identiques re-jouées bit-identiques ; fail-closed sur run
manquant ou triplet incompatible ; aucun résultat fabriqué ; entrée append-only.

## Les refus
Jamais une dorée publiée ; jamais un rung moyenné ; jamais la contamination
ignorée ; jamais un run manqué comblé.
