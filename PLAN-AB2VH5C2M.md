# PLAN GELÉ — AB2VH5C2M (la vague 15)
> L'atelier de validité externe : lever les trois gaps nommés (H7 aux 28 unités,
> le second annotateur, l'indépendance inter-familles) sans fabriquer de données.
> Gelé AVANT toute donnée ; les livraisons appartiennent au développeur.

## Le mandat
(1) **H7 SERVIE** : la campagne aux 28 unités (14 strates × 2, la table officielle
2de7d488… — re-exécution bit-identique exigée) ; les critères d'arrêt D207
(≤3 livraisons/unité, fermeture au premier vert sinon plafond, <10 strates
complètes → H7 NON TESTÉE) ; t apparié t_{0,975;13}=2,160 ; quatre métriques
sans correction de multiplicité nommée. Les livraisons appartiennent au
DÉVELOPPEUR — le laboratoire sert la campagne, l'outillage et l'agrégateur
fail-closed (run manquant = refus, jamais un verdict partiel).
(2) **LE SECOND ANNOTATEUR** : le kit F/L servi (la grille D203, les consignes,
les huit exemples étalonnés E1–E8) ; le calculateur κ re-autotesté (κ≥0,61 SUR
n≥50 doubles — les DEUX conditions conjointes) ; le protocole d'arbitrage en
cinq points (troisième lecture au geste, κ officiel sur les deux jeux intacts).
(3) **L'INDÉPENDANCE INTER-FAMILLES** : nommer le confond capacité du 1.5B
(0/64 récitation) ; la dérivation des 128 constantes + un échantillon de tâches
de notation sur une SECONDE famille CAPABLE (≥30B ou autre vendor API) — zéro
divergence contre les définitions mathématiques exigé, tout écart nommé. La
seconde famille au geste si l'endpoint n'est pas exposé — le gap nommé sans
aucun chiffre fabriqué.

## Les gestes
1. Le plan gelé ; la table de tirage H7 re-exécutée bit-identique (empreinte
   confrontée à 2de7d488…).
2. Le serveur de campagne + l'agrégateur fail-closed + la table des statuts.
3. Le kit annotateur F/L (grille, consignes, E1–E8, calculateur κ + ses quatre
   fixtures, l'arbitrage 5 points).
4. Le kit d'indépendance (les 128 constantes + l'échantillon de notation, la
   confrontation mécanique) ; le geste au développeur si l'endpoint manque.

## La vérification après modifications
Autotests κ verts ; table de tirage re-exécutée bit-identique ; AUCUNE annotation
fabriquée ; AUCUN verdict H7 publié sans livraisons recoupées ; gaps nommés au
registre ; entrée append-only.

## Les refus
Jamais une annotation fabriquée ; jamais un verdict H7 sans livraisons ; jamais
le confond capacité masqué ; jamais une strate incomplète lue comme testée.
