# PLAN GELÉ — 3X9CF4E5D (la vague 15)
> L'atelier triade-gym : livrer l'environnement d'entraînement et la mesure
> headline qui fait du gap nommé le critère de succès, sans affaiblir aucun juge.
> Gelé AVANT toute mesure ; l'empreinte du plan headline précède la première donnée.

## Le mandat
(1) **TRIADE-GYM** : observer un fragment de carte → émettre une notation →
récompense TYPÉE multi-niveaux (syntaxe → expansion → round-trip → oracle →
mutation) ; LA RÉCOMPENSE = LE VERDICT DU JUGE, jamais la similarité à une
référence (anti-récitation) ; les checks anti-hacking (les contrôles de
falsification de P2 font partie de la récompense) ; le rung terrain jamais une
récompense barato (geste développeur).
(2) **LES RECETTES SFT/DPO/RLVR agnostiques en famille** (format des données,
hyperparams, budget compute consigné) ; les paires DPO (notation verte vs refusée
pour le MÊME contrat) extraites des campagnes ; les adapters de référence
optionnels aux versions majeures (≥2 familles si compute, sinon LE GAP NOMMÉ) ;
les cas difficiles des rapports adopteurs (feedback F/L) au curriculum comme
nouveaux exemples + nouvelles tâches held-out.
(3) **LA MESURE HEADLINE PRÉ-ENREGISTRÉE** (empreinte AVANT) : avant/après
entraînement sur les tâches held-out, mêmes graines et juges ; faisabilité
≥15/18 à ≤4 500 tokens par changement validé ; les opérandes non arrondis
publiés ; périmètres étiquetés ; licence/œuvre-dérivée stating clair ; aucun
chiffre fabriqué — la lecture défavorable consignée si la cible est manquée.

## Les gestes
1. Le plan gelé ; le gym (les cinq niveaux de récompense typée, les contrôles
   anti-hacking embarqués à la récompense).
2. Les recettes SFT/DPO/RLVR + l'extraction mécanique des paires DPO depuis les
   campagnes.
3. Le plan headline pré-enregistré (l'empreinte gelée AVANT la mesure).
4. Le registre avant/après re-jouable (graines identiques, mêmes juges) — le
   compute au geste développeur si l'endpoint manque, le gap nommé.

## La vérification après modifications
Récompense = verdict du juge VÉRIFIÉ (pas de string-match) ; anti-hacking
attrapé (un jeu du juge refusé) ; juges multi-niveaux intacts ; avant/après
re-joué à graines identiques, mêmes juges, empreintes conformes ; faisabilité +
coût publiés aux opérandes ; lecture défavorable consignée si cible manquée ;
aucun coffre réel touché ; entrée append-only.

## Les refus
Jamais la récompense détournée en similarité ; jamais un juge affaibli ; jamais
un chiffre d'entraînement fabriqué ; jamais le rung terrain simulé.
