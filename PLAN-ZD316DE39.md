# PLAN GELÉ — ZD316DE39 (la vague 15)
> L'atelier du guide d'agent : rendre le kit utilisable par n'importe quel LLM
> capable, et mesurable comparativement — guide indépendant du modèle, sonde de
> capacité AVANT investissement, bench pré-enregistré embarqué.
> Gelé AVANT toute mesure.

## Le mandat
(1) **LE GUIDE D'AGENT INDÉPENDANT DU MODÈLE** : les 11 règles, la boucle en 7
étapes, la grammaire des refus nommés, les budgets adoptés (627/674/2 200, les
opérandes non arrondis publiés), le pointeur seul + ses 4 refus, les gabarits
versionnés ; LA DÉGRADATION GRÂCIEUSE NOMMÉE (response_format absent → grammaire
au prompt + validateurs, jamais un juge affaibli — le constat TPL-ADD-v4
reconduit).
(2) **LA SONDE DE CAPACITÉ AVANT INVESTISSEMENT** : la dérivation des 128
constantes depuis les définitions mathématiques + le smoke test de notation ; le
kit NOMME la frontière du modèle (le finding 0/64 du 1.5B fait foi — un modèle
trop faible échouera à l'ajouter : conseil fail-closed, pas gatekeeping).
(3) **LE BENCH PRÉ-ENREGISTRÉ EMBARQUÉ** : les 18 tâches locate/edit/add, graines
consignées, juges intacts, schéma JSONL append-only, budgets et périmètres
étiquetés ; le gel de l'empreinte du plan AVANT toute mesure.

## Les gestes
1. Le plan gelé ; le guide (les 11 règles, la boucle 7 étapes, les budgets aux
   opérandes publiés, le pointeur seul, la dégradation gracieuse nommée).
2. La sonde (128 constantes + smoke de notation, la frontière nommée).
3. Le bench embarqué (18 tâches, graines, JSONL append-only, étiquettes).
4. Le dry-run sur une seconde famille CAPABLE si disponible, sinon le gap nommé
   sans aucun chiffre fabriqué.

## La vérification après modifications
Graines identiques re-jouées bit-identiques ; contrôles de falsification des
juges re-verts (un octet muté au home space attrapé, gle 87 → −6) ;
re-tokenisation indépendante ±1 token ; AUCUNE ancre de confiance du projet
expédiée ; entrée append-only.

## Les refus
Jamais une ancre de confiance expédiée ; jamais un juge affaibli pour la
dégradation gracieuse ; jamais un chiffre de dry-run fabriqué.
