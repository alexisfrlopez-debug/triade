CE QUE LE TEST EXIGE :
  Exige Python 3. L'AUTOTEST du calculateur kappa de Cohen est la
  preuve a froid [trois cas synthetiques au k calculable a la
  main] ; le calcul vit le jour des DEUX jeux d'annotations [le
  seuil PRE-ENREGISTRE : k superieur ou egal a 0,61 - D189].
  CE QUI MANQUE, consigne jamais maquille : le SECOND
  ANNOTATEUR [a recruter] et le SECOND DOMAINE [en attente
  d'une vraie commande] - aucun des deux ne s'automatise.

CE QUI RESTE À VOTRE MAIN (jamais automatisé) :
  recruter le second annotateur, produire les DEUX jeux
  d'annotations [le CSV : id,classe - un fichier par annotateur],
  puis vivre le calcul au choix 2 du menu.

LE RENVOI : le dossier de run ENTIER (ce dossier, témoins et preuves
compris) repart au coffre /test — dossier Drive « Triade » → « test ».
Le labo recoupe sur pièces : jamais avant le run, jamais sans pièces ;
un écart nommé est un RÉSULTAT (D189), jamais un échec à maquiller.

LA TRANSPARENCE : le paquet interne est un zip ordinaire — quiconque
le désire peut l'ouvrir et tout comparer lui-même. Les empreintes
complètes vivent dans le fichier .bat lui-même, gravées en clair.
