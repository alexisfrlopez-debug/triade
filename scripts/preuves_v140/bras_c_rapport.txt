LE BRAS DE RÉFÉRENCE COMPILATEUR — v0.14.0 (le plan pré-enregistré D193 ; les critères CA1-CA5)

NOTE D'INTERPRÉTATION : loupe-01 « saine » est la session née entière — la cascade complète (fenêtre + panneau d'empreintes) ; sa médiane élevée cache la queue légère des refus, le CSV porte min/max. ADAPTATION DU PANNEAU : le camp C calcule la moitié sha256 du panneau (le md5 C du banc v0.11.0 fut écarté comme fautif — aucun md5 C audité n'existe au labo) : les comptes de loupe-01 saine ne sont PAS à travail égal, l'écart est nommé. La taille de loupe-05 A (384 o) EXCLUT les blocs sha hérités (tls13-01..04, ~765 o au scellé) que le camp C embarque (1707 o) — l'héritage PAR LA CARTE est un partage, pas une copie : la comparaison honnête est 384+765 contre 1707.
écart nommé : clang ABSENT du laboratoire — gcc 14.2 -O2/-Os tient la place (le précédent v0.11.0)
adaptations nommées (CA4) : le round-trip EXCLU du camp C (la commande) ; K2 camp A = le DÉCODAGE capstone (le round-trip keystone de v0.11.0 non rejoué, l'écart nommé) ; K2 camp C = les comptes d'appels OS contre la référence (les blocs OS seuls) ; la comparaison de loupe-13 par memcmp du C (l'équivalent compilé du libc-02 hérité).
