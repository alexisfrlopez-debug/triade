     refuse : le VRAI chargeur est SSE). LA FORME DE LA LIGNÉE : cinq
     push (« push rbx », « push r12 », « push r13 », « push r14 »,
     « push r15 ») puis « sub rsp, 0x40 » — 104 octets en tout, rsp ≡ 0
     (mod 16) à chaque appel, et la place des arguments 5+ existe.

D16 — r13 NON SAUVÉ : tu sauves le verdict de l'appelé dans r13 (non
     volatil) mais ton prologue ne pousse que rbx et r12 — r13 détruit,
     le sentinelle du harnais le nommera. Couvert par les CINQ push de
     D15 (r13 y vit).

D17 — LA SYNTAXE DES MOTS MÉMOIRE : « mov dword [rsp+0x20], 3 » est

; spec : ouvrir fichier, initialiser session, naître composants (loupe-02/07) ou verdict.
; choix : vérifier E4 (session ouverte) d'abord. Loupe04 pour cadre vierge. Mesure chemin.
; appelés : LOUPE04, LOUPE02, LOUPE07, LOUPE03, LIBC01. IAT : CreateFileW, GetFileSizeEx, CloseHandle, GetLastError.
; ordre : E4 -> LOUPE04 -> CreateFileW (gestion erreurs) -> stocker poignée/taille -> vérifier borne -> mesurer chemin -> copier chemin -> naissance session (LOUPE07 puis LOUPE02 si taille>0) -> gestion erreur appelés -> retour.
; ABI : msx64. Registres non-volatils sauvegardés si utilisés. rsp aligné 16.
; CORRECTIONS : D1 (lea reg, [rip + CADRE] puis reg + offset), D2 (cmp rax, -1), D3 (arg pile 5-7 écrits),
; D4 (cadre pile : push rbx, sub rsp, 0x40), D5 (sauver rcx en r12), D6 (520 littéral), D7 (word ptr),
; D8 (LOUPE02 avant LOUPE07 si taille>0), D9 (sauver verdict avant LOUPE03), D10 (chemin erreur distinct),
; D11 (retirer push/pop hors_perimetre), D12 (copie r8+2 octets), D13 (source = r12).

; --- Préambule et vérification E4 (session déjà ouverte) ---
push rbx
push r12
sub rsp, 0x30
mov rbx, [rip + CADRE + 528] ; rbx = poignée du cadre
cmp rbx, -1
jne .verdict_deja_ouvert

; --- Pose du cadre vierge (LOUPE04) ---
call LOUPE04 ; rax = 0, cadre zéro, poignée = -1

; --- Appel CreateFileW ---
mov r9, 0
mov r8, 1 ; FILE_SHARE_READ
mov edx, 0xC0000000 ; GENERIC_READ | GENERIC_WRITE
mov dword [rsp+0x20], 3 ; OPEN_EXISTING
mov dword [rsp+0x28], 0
mov dword [rsp+0x30], 0

cmp rax, -1
je .erreur_os_create ; rax = -1 (erreur) ou handle

; --- Succès CreateFileW : stocker la poignée ---

; --- Appel GetFileSizeEx pour obtenir la taille ---

; --- Vérifier la taille (Q2 : BORNE_TAILLE) ---
mov rax, [rip + CADRE + 520]
cmp rax, 0x80000000 ; 2 Gio
ja .hors_perimetre

; --- Mesurer la longueur du chemin (UTF-16, NUL-terminé) ---
xor r8, r8 ; r8d = nombre d'octets à copier (compteur)
.loop_mesure:
movzx eax, word ptr [r12 + r8] ; lire 1 caractère UTF-16 (2 octets)
test eax, eax ; est-ce le NUL ?
jz .copie_chemin
add r8, 2 ; pas de NUL, on continue
cmp r8d, 520 ; 260 caractères max * 2
jb .loop_mesure

; --- Chemin trop long (260+ sans NUL) ---
mov rcx, [rip + CADRE + 528] ; rcx = poignée
call qword ptr [rip + IAT_CLOSEHANDLE]

mov eax, -5
add rsp, 0x30
pop r12
pop rbx
ret

.copie_chemin:
; --- Copier le chemin dans le cadre (LIBC01) ---
lea rcx, [rip + CADRE] ; destination = cadre.chemin
mov rdx, r12 ; source = chemin sauvé (r12)
lea r8, [r8 + 2] ; r8d = nombre d'octets (longueur + NUL)
call LIBC01

; --- Initialiser vue et curseur (déjà fait par LOUPE04) ---
; [CADRE+536] = 0, [CADRE+544] = 0

; --- Naissance de la session : LOUPE02 (fenêtre SI taille > 0) ---

test rax, rax
jz .naissance_panneau ; taille = 0, pas de fenêtre

test eax, eax
jne .appel_echoue ; LOUPE02 a rendu une erreur, on propage

; --- Naissance de la session : LOUPE07 (empreintes, TOUJOURS) ---
.naissance_panneau:
lea rcx, [rip + EMPREINTES] ; rcx = pointeur vers le panneau
call LOUPE07
test eax, eax
jne .appel_echoue ; LOUPE07 a rendu une erreur, on propage

; --- Succès final ---
.succes:

add rsp, 0x30
pop r12
pop rbx
ret

; --- Gestion des erreurs OS après CreateFileW ---
.erreur_os_create:

cmp eax, 2 ; ERROR_FILE_NOT_FOUND

LES SYMBOLES DU PLAN (par nom, dans le brouillon) :

L'ABI msx64 (le profil ; l'audit statique du build la vérifie) :
  - les arguments 1 à 4 : rcx, rdx, r8, r9 ;
  - les arguments 5 ET PLUS vivent à [rsp+0x20], [rsp+0x28], [rsp+0x30]…

  - rsp ≡ 0 (mod 16) à CHAQUE appel (compte tes push/pop/sub/add) ;
  - les registres non volatils (rbx, rbp, rdi, rsi, r12 à r15) rendus
    INTACTS (sauve-les si tu les utilises) ;
  - le verdict : rax signé 32 bits (la table des verdicts).

LES FEUILLES (la sémantique des quatre) :
  CreateFileW(lpFileName, dwDesiredAccess, dwShareMode, lpSecurityAttributes,
              dwCreationDisposition, dwFlagsAndAttributes, hTemplateFile)
    7 arguments : rcx = le chemin UTF-16 ; rdx = 0xC0000000
    (GENERIC_READ|GENERIC_WRITE) ; r8 = 1 (FILE_SHARE_READ, offert jamais
    reçu) ; r9 = 0 ; [rsp+0x20] = 3 (OPEN_EXISTING) ; [rsp+0x28] = 0 ;
    [rsp+0x30] = 0. Rend la poignée, ou -1 (INVALID_HANDLE_VALUE) au refus
    (alors GetLastError parle).
  GetFileSizeEx(hFile, lpFileSize) : rcx = la poignée, rdx = le pointeur

  CloseHandle(hObject) : rcx = la poignée ; rend non-zéro au succès.
  GetLastError() : aucun argument ; rend le code (2 = FILE_NOT_FOUND,
    3 = PATH_NOT_FOUND, 32 = SHARING_VIOLATION, 5 = ACCESS_DENIED).

L'ORDRE DU GESTE (le contrat le dit, le réseau l'exige) :
  1. E4 D'ABORD : la poignée du cadre (@+528) lue — si ≠ -1, la session
     est déjà ouverte : rax = -5, RIEN TOUCHÉ (l'ancien cadre demeure
     INTACT — le test précède TOUT geste, même loupe-04) ;
  2. LOUPE04 : le cadre vierge posé (les zéros, la poignée INVALIDE) ;
  3. CreateFileW : au refus (-1), GetLastError → la table (2 ou 3 → -2 ;
     32 → -7 ; le reste → -6), la barre le nomme, RETOUR ;
  4. la poignée au cadre (+528), GetFileSizeEx → la taille au cadre (+520) ;
  5. Q2 LA BORNE : taille > 0x80000000 (comparaison NON signée, la taille
     est un qword) → CloseHandle (la poignée JAMAIS pendante), LOUPE04
     (le cadre re-vierge : la session échouée ne laisse RIEN), rax = -3 ;
  6. LA MESURE DU CHEMIN : les caractères UTF-16 comptés jusqu'au NUL ;
     si 260 caractères SANS NUL → CloseHandle, LOUPE04, rax = -5 (jamais
     un débordement) ;
  7. LA COPIE : le chemin copié au cadre (+0) PAR LIBC01 (jamais octet
     par octet réécrit) — n = (longueur + 1) × 2 octets, le NUL compris ;
     la vue = 0, le curseur = 0 (loupe-04 les a posés) ;
  8. Q4 LA SESSION NÉE ENTIÈRE : si taille > 0, LOUPE02 (la fenêtre à la
     vue 0 — argument ecx = 0) ; puis LOUPE07 (le panneau — rcx = le
     pointeur EMPREINTES, posé par lea rcx, [rip + EMPREINTES]) ; le vide
     SAUTE la fenêtre mais PAS le panneau ;
  9. LE REFUS D'UN APPELÉ (loupe-02 ou loupe-07 rend un eax négatif) :
     LOUPE03 (la session se clôt — la poignée rendue, le cadre re-vierge),
     le verdict de l'appelé remonte TEL QUEL dans rax ;
  10. le succès : rax = 0.

================================================================================
