Les vecteurs sont les instances matérielles du CONTRAT. Chacun est une preuve concrète, une attente sémantique absolue. Le code machine sera jugé sur sa capacité à reproduire exactement ces résultats.

**1. Vecteur Nominal 1 (V1) : La Doré**

La ligne se termine par un octet NUL (`\x00`).

*   **Preuve Attendue** : La sortie octet par octet doit correspondre exactement à la ligne générée par une fonction Python respectant scrupuleusement les règles du contrat. L'alignement des colonnes doit être parfait.

**2. Vecteur Nominal 2 (V2) : Le Différentiel**
*   **Scénario** : 10 000 exécutions avec des entrées aléatoires :

*   **Attendu de Contrat (sémantique)** :
    *   **Q1 (Format)** : Pour chaque exécution, la sortie de 77 octets doit respecter scrupuleusement le format `SSSSSSSS  HH...HH  HH...HH  MMMMMMMMMMMMMMMMM`.

    *   **Q4 (Retour)** : `rax` doit toujours être `0` après chaque exécution.
*   **Preuve Attendue** : La sortie de chaque exécution doit être identique, octet par octet, à la sortie d'une fonction de référence (en Python ou autre) implémentant les mêmes règles. C'est le test de robustesse et de conformité.

**3. Vecteur de Rejet (V3) : Les Entrées Invalides**
*   **Scénario** : Trois appels distincts avec des paramètres violant le contrat.

**4. Vecteur de Falsification (V4) : Le Piège**
*   **Scénario** : Une entrée valide (ex: `rdx=16`, `r9=0`, `rcx` pointant sur 16 octets connus) mais une sortie contenant une seule erreur, par exemple :
    *   Un espace manquant entre deux groupes hexadécimaux : `XX XX XX XX XX XX XX XX XX XX...`
    *   Un point de remplacement (`.`) utilisé à la place d'un espace dans la colonne ASCII.
    *   Une majuscule en minuscule en hexadécimal (`a` au lieu de `A`).
*   **Attendu de Contrat (sémantique)** :
    *   **Échec** : Le verdict est un échec total. La moindre déviation par rapport au format contracté est une falsification.
*   **Preuve Attendue** : L'oracle à scénarios (différentiel) détectera la divergence et rendra un verdict négatif. Ce vecteur n'est pas un test de passage, mais une validation que le rejet de toute non-conformité est correct.
