LE MODÈLE (la sémantique du contrat, une fonction) :

  def modele_ligne(decalage, octets):
      # la longueur valide 1..16, le décalage multiple de 16 ≤ 0x7FFFFFFF
      # (P4 : BORNE_TAILLE le garantit — le modèle ne vérifie pas ce que
      # le plan garantit) ;
      # Q1 : « SSSSSSSS·HH HH HH HH HH HH HH HH··HH HH HH HH HH HH HH HH··
      #        MMMMMMMMMMMMMMMMM » + NUL — 8 chiffres hex MAJUSCULES du
      # décalage (grand-boutiste), 2 espaces, 16 groupes « HH » séparés
      # d'un espace (le médian DOUBLÉ après le huitième), 2 espaces, le
      # miroir ASCII de 16, le NUL — EXACTEMENT 77 o, jamais un de plus ;
      s = f"{decalage:08X}  "
      g = [f"{b:02X}" if i < len(octets) else "  "
           for i, b in enumerate(octets + b"\x00" * (16 - len(octets)))]
      s += " ".join(g[:8]) + "  " + " ".join(g[8:]) + "  "
      # Q2 : le miroir — 0x20..0x7E le caractère, tout autre le point
      miroir = "".join(chr(b) if 0x20 <= b <= 0x7E else "."
                       for b in octets[:16])
      s += miroir + " " * (16 - len(miroir))
      # Q3 : la ligne incomplète — les groupes au-delà de la longueur
      # demeurent deux espaces, le miroir au-delà un espace : la colonne
      # ASCII ne bouge JAMAIS (l'alignement est un invariant)
      return s.encode("latin-1") + b"\x00"          # 77 o exacts

  LES POSITIONS dérivées du format (la colonne ASCII est un invariant) :
    [0..7]    les huit chiffres du décalage (bits 31..0, nibble à nibble)
    [8..9]    deux espaces
    [10..32]  les groupes 0..7 : « HH » à 10 + 3·i, l'espace entre eux
    [33..34]  l'espace médian DOUBLÉ (entre les groupes 7 et 8)
    [35..57]  les groupes 8..15 : « HH » à 35 + 3·(i − 8)
    [58..59]  deux espaces
    [60..75]  le miroir ASCII : 60 + i
    [76]      le NUL final

  LE VERDICT (Q4) : rax = 0 ; les rejets (E1/E2/E3) : rax = −5, RIEN
  écrit — la sortie empoisonnée demeure INTACTE (I2 : les bornes P2
  vérifiées AVANT la première écriture).
