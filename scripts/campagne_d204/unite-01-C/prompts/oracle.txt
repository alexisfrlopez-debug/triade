Tu es le même auteur du domaine Loupe au laboratoire TRIADE — le bras C de
la campagne D204 (le flux conventionnel, C + gcc). Le bloc loupe-01 ·
ouvrir sera écrit en C bientôt ; AVANT l'écriture (écrit-avant-code, la
charte), tu dérives DU CONTRAT L'ORACLE — les attentes du juge, vecteur par
vecteur. Le juge est un modèle indépendant Python (hashlib, les découpes) :
il ne lira JAMAIS les octets de ton source — il compose l'attendu depuis le
contrat seul et le confronte à l'état observé (le cadre et le panneau de la
pièce, aux offsets du plan).

LE CONTRAT (loupe/I/loupe-01-ouvrir.md, révision 3) — les clauses qui font
l'oracle :
- Q1 CreateFileW(GENERIC_LECTURE|GENERIC_ECRITURE, PARTAGE_LECTURE,
  OUVRIR_EXISTANT) — succès : la poignée au cadre (+528), la taille par
  GetFileSizeEx au cadre (+520) ;
- Q2 la BORNE NOMMÉE : taille > 2 Gio → verdict -3, la poignée FERMÉE
  AVANT le retour ;
- Q3 le chemin COPIÉ au cadre (+0), la vue = 0 (+536), le curseur = 0
  (+544) — le remplissage = min(384, taille) (+552), le tampon du cadre
  (+568, 384 o) == la découpe du fichier [0, remplissage) ;
- Q4 la session NÉE ENTIÈRE : la fenêtre à la vue 0 SEULEMENT SI
  taille > 0 ; puis le panneau — les empreintes du fichier ENTIER
  (48 o : md5 (16) puis sha256 (32), hashlib du contenu entier), LE VIDE
  AUSSI (d41d8cd9… + e3b0c442…) ;
- Q5 rax = 0 ;
- E1 ERROR_FILE_NOT_FOUND (2) ou ERROR_PATH_NOT_FOUND (3) → -2 ;
- E2 ERROR_SHARING_VIOLATION (32) → -7 ;
- E3 tout autre refus → -6 (gle consigné au journal du harnais) ;
- E4 session déjà ouverte (la poignée du cadre ≠ INVALIDE) → -5, RIEN
  TOUCHÉ (le cadre ET le panneau de l'ancienne session relus identiques,
  octet par octet) ;
- P1 le chemin plus long que la capacité du cadre (le kit appelle un
  chemin de 260 caractères, session fermée) : le système refuse
  lui-même le chemin trop long — le verdict exact est consigné TEL QUEL
  parmi -2, -5 ou -6 (le kit accepte les trois, la traduction de la
  table fait foi), RIEN au cadre (jamais un débordement) ;
- V4 la falsification : la taille mutée d'un octet au cadre après
  l'ouverture → l'écran attendu (composé du modèle) diverge de l'état lu,
  l'oracle échoue — LA FALSIFICATION DEMANDÉE.

LA DISCIPLINE DU BRAS C (le kit terrain, le même aux deux bras) : ta
pièce sera une DLL PE32+ chargée DONT_RESOLVE — le scénario résout
LUI-MÊME les six feuilles kernel32 (CreateFileW, GetFileSizeEx,
SetFilePointerEx, ReadFile, CloseHandle, GetLastError) dans TA table
d'imports réelle, découvre tes fonctions loupe_01_ouvrir et
loupe_03_fermer et tes données cadre (960 o) et panneau (48 o) PAR TA
TABLE D'EXPORTS, appelle loupe_01_ouvrir(chemin) (l'ABI est la tienne —
le C), lit le cadre et le panneau aux offsets du plan. loupe_03_fermer
clôt la session (la poignée refermée, la session rouverte pour l'appel
suivant) — le juge l'appelle entre les vecteurs.
