LISEZMOI — LE KIT D205 : LA MESURE AVANT/APRÈS SHA-NI (correctif n° 2, 12/11)
=======================================================================

POURQUOI CE CORRECTIF N° 2 REMPLACE LE PRÉCÉDENT (le récit en trois actes)
  ACTE 1 — LE PREMIER KIT PLANTAIT :
      OSError: exception: access violation writing 0xFFFFFFFFD4991000
  L'adresse fautive était l'extension de signe d'un POINTEUR 64 BITS
  TRONQUÉ en 32 bits signés. La cause : un appel système qui rend un
  pointeur (VirtualAlloc) gardait son type de retour PAR DÉFAUT.
  LE CORRECTIF N° 1 : chaque API rendant un pointeur porte
  restype = c_void_p EXPLICITE ; les adresses vivent en entiers non
  signés 64 bits ; et CHAQUE écriture dans l'arène est bornée fin
  incluse — un débordement est un refus nommé AVANT le premier octet.
  ACTE 2 — VOTRE RUN DU 12/11 10:02 A PRIS LE PLI DES DEUX CÔTÉS :
  le kit corrigé n'a PLUS planté (l'arène allouée, les pièces posées,
  les empreintes recoupées) — puis il a nommé son échec : « T0.silicium :
  les extensions SHA sont présentes ». Le silicium de votre machine
  n'a PAS SHA-NI (CPUID feuille 7, EBX bit 29 = 0) : le kit a refusé de
  mesurer, exactement comme conçu — il ne peut pas inventer le
  silicium. MAIS le verdict était MUET sur l'identité du silicium : le
  constat CPUID (fabricant, famille, modèle) n'existait que sur la
  console, et la machine n'était nulle part.
  ACTE 3 — LE CORRECTIF N° 2 (une preuve d'échec doit être
  AUTO-PORTANTE) : la machine est JOURNALISÉE à l'ouverture, le constat
  CPUID est JOURNALISÉ, et le verdict d'échec T0.silicium PORTE le
  constat complet du silicium. Le prochain run — vert ou nommé — se
  suffit à lui-même.
  Le kit fut ÉPROUVÉ AU LABORATOIRE par les DEUX chemins (VERDICT VERT
  joint dans preuves-run-shani-autotest-labo-v2/ : pièces scellées
  recoupées, vecteur FIPS exact par TROIS lecteurs, adversaire tranché,
  mesure rendue 6,37× sur le silicium du laboratoire, pièces relues
  intactes ; et le chemin nommé : le silicium masqué rend l'ÉCHEC
  NOMMÉ auto-portant du premier coup).

CE QUE LE KIT MESURE
  L'AVANT : tls13-02 — la compression SHA-256 de LA PIÈCE SCELLÉE
      proxy.exe 1.0.0 (446279f3…), appelée à son adresse dans l'image
      mémoire étendue posée dans l'arène (la découpe honnête : la table
      K en .rdata est lue par RIP-relatif).
  L'APRÈS : shani_compress — la MÊME compression écrite avec les
      EXTENSIONS SHA du silicium (sha256rnds2 / sha256msg1 / sha256msg2),
      assemblée dans le blob moteur-shani.bin (source moteur-shani.s ;
      dérivée des pseudocodes officiels, éprouvée contre le vecteur FIPS
      « abc » et un recoup hashlib de mille blocs AVANT tout usage).
  La mesure : 101 échantillons × 256 compressions par camp, affinité
  posée à un cœur, RDTSC sérialisé, horloge QPC en contrepoint — la
  MÉDIANE cycles/compression de chaque camp et LE RAPPORT, sur TROIS
  blocs (le vecteur abc, un aléa déterministe, des zéros).
  Le gain mesuré APPARTIENT À VOTRE MACHINE : aucun chiffre n'est
  généralisé, aucun statut n'est fabriqué.

COMMENT L'EXÉCUTER (votre machine Windows)
  1. Ouvrez une invite de commandes DANS ce dossier kit-shani.
  2. Tapez :  scenario-shani.py        (ou : python scenario-shani.py)
  3. Attendez environ une à deux minutes — chaque geste s'imprime et
     se consigne au fur et à mesure.
  4. Le verdict s'écrit à la fin : VERT (tout tint) ou ÉCHEC NOMMÉ
     (la ligne nomme le défaut — un échec se renvoie TEL QUEL).

PRÉCISIONS HONNÊTES
  — Le silicium est lu par CPUID : un CPU SANS extensions SHA rend un
    ÉCHEC NOMMÉ AUTO-PORTANT (le verdict porte le fabricant, la famille,
    le modèle, le pas et le bit 29 — le kit ne peut pas inventer le
    silicium). Sur une machine sans SHA-NI, la mesure avant/après
    N'EXISTE PAS : c'est un fait de silicium, pas un défaut du kit.
  — L'état du turbo n'est pas sondable simplement : consignez-le à la
    main dans le témoin si votre BIOS le permet.
  — L'affinité cœur 0 : si le système la refuse, elle est consignée et
    la mesure continue (le témoin le dit).
  — Sous Linux, le même script tourne en AUTOTEST laboratoire (le
    mécanisme seul, AUCUN statut terrain) — c'est ainsi qu'il fut
    éprouvé avant de vous être livré.
