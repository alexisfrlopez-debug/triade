# PLAN GELÉ — 0I4PKZBYR (la vague 15)
> L'atelier du dataset de réplication : faire des runs adopteurs le dataset codé
> et anonymisé, sans fragmenter la base d'évidence.
> Gelé AVANT toute donnée ; l'outil rapport précède le premier rapport.

## Le mandat
(1) **L'OUTIL RAPPORT (trio D122)** : journal d'écran + boîte noire horodatée +
bouton envoyer — zéro phrase, zéro chemin réel, zéro clé ; le scan de secrets en
porte de soumission (LE CONTRÔLE NÉGATIF : une phrase de test marquée plantée
dans un rapport DOIT être refusée).
(2) **LE CODAGE F/L OBLIGATOIRE** : la grille D203 (correspondance un-pour-un,
les huit exemples étalonnés E1–E8) ; le calculateur κ re-autotesté (les quatre
fixtures ; κ≥0,61 SUR n≥50, les deux conditions conjointes) ; le protocole
d'arbitrage en cinq points ; le format CSV anonymisé + le manifeste de soumission.
(3) **L'OUTILLAGE H7 GÉNÉRALISÉ** : le tirage stratifié par paires de familles
(les deux ordres par construction), les règles d'arrêt D207 fail-closed, le
t apparié t_{0,975;13}=2,160, les quatre métriques sans correction de
multiplicité nommée ; les livraisons appartiennent à l'adopteur, aucun verdict
fabriqué.

## Les gestes
1. Le plan gelé ; l'outil rapport (le trio D122) + la porte de secrets + le
   contrôle négatif vécu.
2. Le kit annotateur (grille D203, E1–E8, κ + fixtures, arbitrage 5 points) +
   le format CSV anonymisé + le manifeste.
3. L'outillage H7 généralisé (tirage stratifié, arrêt D207, agrégation).
4. Le rapport d'autotests (chaque porte vécue, chaque négatif attrapé).

## La vérification après modifications
Autotests κ verts ; table de tirage re-exécutée bit-identique ; règles d'arrêt
fail-closed éprouvées (strate incomplète → NON TESTÉE, run manquant → refus
nommé) ; anonymat vérifié (aucun chemin réel, aucune clé) ; aucun coffre réel
touché ; entrée append-only.

## Les refus
Jamais un secret dans un rapport ; jamais une annotation fabriquée ; jamais une
strate incomplète lue comme testée ; jamais le coffre réel touché au laboratoire.
