# PLAN GELÉ — VXF37231R (la vague 15)
> L'atelier cohérence : appliquer les extensions documentées-non-appliquées et
> guérir les résidus de cohérence inter-pièces — l'ancrage Rekor/RFC3161, le
> moteur sentinelle Windows, le linter v2 étendu, les packs régénérés.
> Gelé AVANT toute extension ; l'empreinte du plan précède la première pièce.

## Le mandat
(1) **L'ANCRAGE REKOR/RFC3161 des témoins d'époque** : le format du témoin, la
vérification machine OFFLINE des preuves d'inclusion, fail-closed, le delta au
modèle de menace aux deux bords ; LE GESTE RÉSEAU appartient au développeur —
le laboratoire prépare le kit.
(2) **LE MOTEUR SENTINELLE Windows** (SACL + journal 4663 ou ETW — l'exigence
consignée depuis CF2) + les miroirs Windows de la garde RAM ; l'autotest sur
copies de laboratoire à phrase publique marquée (D105).
(3) **LE LINTER v2 ÉTENDU** : les phrases sémantiques retirées (« le compilateur
disparaît » encore en spec §1 vs D182), les plages décisionnelles annoncées vs
entrées listées (Livre ch.11 D75–D250 vs table à D137 ; spec B D75–D251), les
séquences de faisabilité (Table 19 : ajouter 7/18), les claims DOI/version
post-dépôt (manuscrit « v0.23.1 at this writing » vs dépôt v0.23.2 vérifié), les
gallicismes EN (« tranchée », « five-thirds escrow »).

## Les gestes
1. Le plan gelé ; le kit d'ancrage (le format du témoin, la vérification offline
   fail-closed, le delta au modèle de menace).
2. Le moteur sentinelle Windows + les miroirs de la garde RAM + l'autotest D105
   sur copies de laboratoire.
3. Le linter v2 (les cinq classes nommées) + LE CONTRÔLE NÉGATIF (une violation
   plantée par classe DOIT être attrapée).
4. Les cinq pièces passées au linter v2 ; zéro rouge inter-pièces ; les packs
   régénérés si des corrections vivent (les corrections en décisions nouvelles
   et ERRATUM append-only, JAMAIS en réécriture des entrées historiques).

## La vérification après modifications
Contrôle négatif du linter vécu (une violation plantée par classe attrapée) ;
zéro rouge inter-pièces sur les pièces régénérées ; la vérification offline des
preuves d'ancrage ; aucun coffre réel touché ; sceau 14/14 avant/après ; entrée
append-only ; les corrections vivent en décisions nouvelles, jamais en
réécriture des entrées historiques.

## Les refus
Jamais le verbatim historique réécrit ; jamais une violation du linter tolérée ;
jamais le geste réseau exécuté au laboratoire ; jamais un pack régénéré sans
linter vert.
