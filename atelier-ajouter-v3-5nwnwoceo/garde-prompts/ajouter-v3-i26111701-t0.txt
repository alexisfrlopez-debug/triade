LE CONTRAT DE COUCHE I (mot pour mot) :
loupe-07 · cumul : les empreintes du fichier entier au panneau · révision 1
Intention : LES empreintes du fichier ENTIER — MD5 ET SHA-256, la double
empreinte du panneau, née à l'ouverture (loupe-01 l'appelle) et
renaissant à chaque sauvegarde (loupe-17 l'appelle) : le panneau
d'empreintes est TOUJOURS celui du DISQUE, jamais un mensonge de
session. Deux passages par fenêtres glissantes (loupe-05 puis loupe-06)
— un fichier de 2 Gio passe, jamais tout en mémoire.
Contrat :
  pre  : P1 la session est ouverte ; P2 rcx = la sortie, 48 o
             accessibles (md5[16] @ +0 · sha256[32] @ +16 — la
             disposition du panneau, la source unique).
  post : Q1 la sortie = (MD5(F), SHA-256(F)) — F le fichier ENTIER du
             disque, par DEUX passages : loupe-05(0, taille, sortie+16)
             PUIS loupe-06(0, taille, sortie+0) — la composition
             seule, chacun son passage ;
         Q2 la ZONE_EMPREINTES du plan d'adressage EST la sortie
             canonique (loupe-01 et loupe-17 la passent : le panneau
             de la barre la lit — jamais une seconde copie) ;
         Q3 rax = 0.
  inv  : I1 AUCUNE entrée IAT, AUCUN site syscall : le bloc est LA
             COMPOSITION (loupe-05 et loupe-06 PAR LA CARTE — le
             miroir des feuilles pures, charte § 9 ; la lecture vit
             dans les blocs composés) ;
         I2 les DEUX passages passent par TAMPON_CUMUL, L'UN APRÈS
             L'AUTRE (l'exclusion de famille : jamais deux flux
             simultanés — l'application est monofile) ;
         I3 le panneau est CELUI DU DISQUE : les écritures du journal
             (non sauvées) n'y figurent PAS — la barre porte l'asté-
             risque qui nomme la divergence (loupe-10 Q1), la vérité
             n'attend pas la sauvegarde ;
         I4 la vue, le curseur et le journal INTACTS (le calcul ne
             touche à rien de la session) ; registres non volatils
             rendus ; NOP, 0x90.
Échecs :
  E1 : sans session (P1) → verdict -4 SESSION, rax = -4.
  E2 : la sortie inutilisable (P2) → verdict -5 ENTRÉE, rax = -5.
  E3 : un refus de lecture des blocs composés (le verdict -6 rendu

TPL-ADD-GRAMMAIRE-v1 — LA GRAMMAIRE EBNF DU CORPS (ce que tu émets) :

  corps        = { ligne } ;
  ligne        = definition | instruction ;
  definition   = etiquette_locale ":" ;
  etiquette_locale = lettre_minuscule { lettre_minuscule | chiffre | "_" } ;
  instruction  = mnemonique [ operande [ "," operande ] ] ;
  operande     = registre | immediat | adresse_memoire | ID | etiquette_locale ;
  registre     = "rax" | "rbx" | "rcx" | "rdx" | "rsi" | "rdi" | "rbp"
               | "rsp" | "r8".."r15" | "eax".."r15d" | "al".."r15b"
               | "xmm0".."xmm15" ;
  immediat     = [ "-" ] ( chiffre { chiffre } | "0x" hexa { hexa } ) ;
  adresse_memoire = "[" registre [ ("+" | "-") ( registre [ "*" ("2"|"4"|"8")
                   | immediat ) ] ] [ ("+" | "-") immediat ] "]" ;
  ID           = ( "LBL" | "CST" ) "-" chiffre chiffre chiffre ;
  saut         = ( "jmp" | "je" | "jne" | "jz" | "jnz" | "ja" | "jae" | "jb"
                 | "jbe" | "jg" | "jge" | "jl" | "jle" | "js" | "jns" )
                 ( ID | etiquette_locale ) ;
  appel        = "call" ( ID | immediat ) ;

LES QUATRE INTERDITS DE FORME (le client REFUSE au nom de la cause, à la
ligne près — AVANT l'assemblage) :
  (a) AUCUN « cmp » mémoire-à-mémoire (un opérande mémoire AU PLUS par
      cmp/test — l'autre est un registre ou un immédiat) ;
  (b) AUCUN « movzx » registre-64 vers registre-64 (la source de movzx
      est 32 bits ou moins : « movzx rax, ecx » admis, « movzx rax, rcx »
      REFUSÉ) ;
  (c) AUCUN désalignement de taille entre destination et source d'un mov
      (« mov eax, rbx » REFUSÉ — 32 vers 64 : les tailles s'accordent) ;
  (d) AUCUN symbole en clair (WM_PAINT, ANSI_FIXED_FONT, MB_OK…) : la
      VALEUR NUMÉRIQUE littérale ou l'ID du dictionnaire, RIEN D'AUTRE.

REQUÊTE : écris UNIQUEMENT LES LIGNES DE LA LOGIQUE — le corps du
bloc qui vivra entre les balises du squelette. LES RÈGLES : (1)
toute étiquette de saut DU BLOC se note par SON ID (ex. « je
LBL-005 »), jamais en clair ; (2) tout appel IAT ou direct se
note par SON ID (ex. « call CST-002 ») ; (3) toute constante se
note par SON ID si elle y vit, SINON par sa VALEUR NUMÉRIQUE
littérale (ex. « cmp r13, CST-001 » ou « cmp eax, 15 ») — JAMAIS
un nom de symbole en clair (WM_PAINT, ANSI_FIXED_FONT : la valeur
ou l'ID, rien d'autre) ; (4) tes étiquettes LOCALES à TOI se
définissent « nom : » (un nom court, minuscule : « boucle : »,
« fin : ») et se référent « boucle »/« fin » — N'ÉCRIS JAMAIS
« LBL-xxx : » : les LBL-xxx sont des cibles DÉJÀ RÉSOLUES du
plan, elles ne se définissent pas ; (5) les instructions du
domaine seulement. La PREMIÈRE ligne de ta réponse est la première
instruction, la DERNIÈRE la dernière — aucune balise, aucun
texte d'explication (les commentaires « ; » en fin de ligne sont
admis).
